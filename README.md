# CodeAlpha Task 2 - Exploratory Data Analysis

## Project Title
Exploratory Data Analysis of Book Prices and Ratings

## Objective
The objective of this project is to explore a book dataset,
identify patterns and trends, detect anomalies, and generate
meaningful insights using Python.

## Dataset
The dataset contains 100 book records collected through
web scraping during Task 1.

The dataset includes:
- Book Title
- Price
- Availability
- Rating

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## EDA Performed
The following exploratory analysis was performed:

1. Examined the dataset structure and dimensions.
2. Identified variables and their data types.
3. Checked for missing values.
4. Checked for duplicate records.
5. Calculated basic statistical measures.
6. Analyzed book price distribution.
7. Analyzed rating distribution.
8. Compared prices across different ratings.
9. Identified potential price outliers using the IQR method.
10. Examined the correlation between price and rating.

## Visualizations
The following visualizations were created:

- Book Price Distribution
- Book Rating Distribution
- Price Distribution by Rating

## Key Findings
- The dataset contains 100 book records.
- The average, minimum, and maximum book prices were calculated.
- The distribution of book ratings was analyzed.
- Differences in average prices across ratings were examined.
- Potential price outliers were identified using the IQR method.
- The relationship between book price and rating was examined using correlation analysis.

## Conclusion
Exploratory Data Analysis helped in understanding the
structure, distribution, patterns, relationships, and
potential anomalies present in the book dataset.

This project demonstrates the practical use of Python,
Pandas, NumPy, Matplotlib, and Seaborn for performing
Exploratory Data Analysis.
